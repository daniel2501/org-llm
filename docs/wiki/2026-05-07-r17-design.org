* Summary

*Summary.* R17 advances from "tune one specialist" (R16) to "compose
multiple FOSS specialists into a system that beats Claude." Sweeps
all 10 coordination strategies (C1-C10), adds the FOSS roster's
2026-Q2 newcomers (Kimi K2-Thinking, Qwen3.6-27B, GLM-4.6), and
opens a side-track for speculative decoding + Weaver judge ensemble +
LoRA on the harvested R15+R16 dataset. Working hypothesis: cheap
FOSS + smart composition ≥ single Claude.

*Expanded.* R16 results inform R17 — wait for layer-1 leaders then
graduate them into composition layers. R17 scope is bigger (3-4 days
of cells, ~$200-300; cap raised to $375 per user 2026-05-08) and
explicitly tests whether more FOSS LLMs in clever orchestrations
beat single-strong-Claude on real coding + OS + org-mode work.

* Coordination strategies — C1-C10 sweep

| ID | Pattern                            | What                                                | Test fixture                                |
|----+------------------------------------+-----------------------------------------------------+---------------------------------------------|
| C1 | Hierarchical planner-executor      | Captain (cheap qwen30) plans → specialist executes  | Carry-over from R15/R16 (baseline)          |
| C2 | Plan-Solve-Verify (PSV)            | planner → executor → verifier loop with retry       | New layer over R16 cells                    |
| C3 | Mixture-of-Agents (MoA)            | N proposers in parallel, aggregator synthesizes     | Layer 5 vote — RESERVED for prose tasks per research agent |
| C4 | Tree-of-Thoughts (ToT)             | branch K plans, score, pick best, expand            | New layer for high-stakes tasks (B11 DEC)   |
| C5 | Self-Consistency vote              | N independent plans → modal answer                  | Already wired (DSC); extend to 3-vote       |
| C6 | Reflexion                          | After failure, verbal self-reflection, retry        | New retry-with-reflection wrapper in runtime |
| C7 | Generator-Discriminator            | Generator proposes; critic scores; revise           | New 2-LLM-pair layer over R16 cells         |
| C8 | Begin/end syncs                    | Models exchange interpretation at start, mutual review at end | Multi-specialist team layer        |
| C9 | Symbolic planning                  | Formal planner (PDDL-like) for deterministic parts  | For B40 inbox triage (rule-based skeleton)  |
| C10 | State-tracking scratchpad         | Explicit state object across iterations              | Add to long-horizon cells (B7 docstrings)   |

* Open questions / R18+ candidates

- *Continuous orchestration* — observer LLM watching iterations, intervening
- *Self-coded tools (Phase 29)* — repeated patterns become deterministic
- *Specialty per-handle LoRAs* — distinct LoRAs for @atoz / @data / @geordi
- *Cross-run learning* — feed previous-cell results into current spec
- *Tournament tier* — graduate winners to harder tasks, drop laggards
- *Org-roam hosted vector index* — RAG over user's vault at edit time
- *Modal-hosted full pipeline* — entire R17 self-contained, no OpenRouter
