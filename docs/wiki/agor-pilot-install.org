* Summary

*Summary.* Pilot-install checklist for [[id:1e75cdba-f743-456d-9d0f-07b9e0da33ac][multi-agent-org-llm]]'s
=Agor= integration on the user's Linux + Guix desktop. *Verified
live 2026-05-06 EDT* against =agor-live v0.17.3=, Node v22.14.0,
npm 10.9.2. Per agent-tool-install rule this page is a *checklist
the user runs themselves* — not an automated install. FOSS-first,
user-scope (no =sudo=). Mobile / termux is *out of scope* — see
=/tmp/agor-mobile-termux-verify-2026-05-06.org=.

*Expanded.* Agor ships as npm package =agor-live=. Upstream
install is =npm install -g agor-live=; with the user-scope npm
prefix below it lands in =~/.npm-global/bin/= (no =sudo=,
=guix gc=-safe). First-run is =agor init= → =agor daemon start=
→ smoke harness. The =@libsql/client= glibc-spoof workaround
flagged in the termux verifier is *Bionic-only* and *did not
bite* on Guix glibc (verified). The Guix Node TLS cert-bundle
gotcha (=project_guix_ssl_certs.md=) was already mitigated and
also did not bite. One non-fatal =EBADENGINE= warning surfaced
during =npm install= — documented under *Known gotchas*.

* Install steps (user-scope, verified 2026-05-06 EDT)

The exact pipeline that worked tonight, top to bottom. Everything
stays in =~/.guix-profile= or =~/.npm-global=; *no =sudo=*.

1. *Install Node + npm via Guix (user-scope).* ~50 packages,
   landed clean.

   #+begin_src sh
   guix install node
   ~/.guix-profile/bin/node --version    # → v22.14.0
   ~/.guix-profile/bin/npm  --version    # → 10.9.2
   #+end_src

2. *Point npm at a user-scope prefix* so global bins live under
   =~/.npm-global/bin/= (=guix gc=-safe; never trips EACCES).

   #+begin_src sh
   ~/.guix-profile/bin/npm config set prefix ~/.npm-global
   #+end_src

3. *Add =~/.npm-global/bin= to fish PATH* (file persists across
   shell sessions).

   #+begin_src sh
   # write ~/.config/fish/conf.d/npm-global-path.fish:
   #   fish_add_path -aP $HOME/.npm-global/bin
   #+end_src

4. *Install Agor (user-scope npm).* 826 packages, ~48 s.

   #+begin_src sh
   export PATH="$HOME/.npm-global/bin:$HOME/.guix-profile/bin:$PATH"
   npm install -g agor-live
   agor --version                         # → 0.17.3
   #+end_src

   One =EBADENGINE= warning fires for =md-to-slack@1.1.7=
   (Node 22.14 < required 22.16). *Non-fatal* — that package is
   the Slack message-gateway sub-feature; we're not using it.

5. *Initialize Agor.* Creates =~/.agor/= + local DB + default admin.
   Interactive prompt asks /Enable authentication and multiplayer
   features?/ — answering =n= still seeds the default admin (see
   BUG-4 below).

   #+begin_src sh
   echo "n" | agor init --force
   #+end_src

6. *Start the daemon.* Foregrounds briefly, then backgrounds.

   #+begin_src sh
   agor daemon start
   agor daemon status
   curl -s http://localhost:3030/health   # → 200
   #+end_src

7. *Auth + smoke the REST surface.*

   #+begin_src sh
   agor auth login -e admin@agor.live -p admin   # writes ~/.agor/cli-token
   TOKEN=$(jq -r .accessToken ~/.agor/cli-token)
   curl -s -H "Authorization: Bearer $TOKEN" http://localhost:3030/sessions
   # → {"total":0,"limit":10000,"skip":0,"data":[]}
   #+end_src

8. *Register a repo* (org-llm itself, for the smoke harness).

   #+begin_src sh
   agor repo add-local /home/daniel/repos/org-llm
   # → repo_id: 019dfbd1-abe8-717b-b0b4-099526fe0b65
   #+end_src

* First-spawn smoke test (verified 2026-05-06 EDT)

Use the working harness, not a manual curl recipe:

#+begin_src sh
bash scripts/agor-smoke.sh                       # full pipeline; ≈ $0.07 LLM
SKIP_CLAUDE=1 bash scripts/agor-smoke.sh         # REST primitives only; $0
bash scripts/agor-smoke-v01.sh                   # extended primitives; $0
#+end_src

Live PASS from tonight: 12 s wall, $0.07 LLM, parent→child
genealogy verified in DB. Full flow + exit codes in
=docs/wiki/agor-smoke-recipe.org=. Stop the daemon with =agor daemon stop= when done.

* Credential management (verified 2026-05-06 EDT)

Default admin password lives in =pass= per the agent-tool-install
rule (no plaintext on disk, no shell history exposure):

#+begin_src sh
pass insert -m org-llm/agor/admin-password   # paste "admin" then Ctrl-D
agor auth login -e admin@agor.live -p $(pass org-llm/agor/admin-password)
#+end_src

Rationale: =feedback_agent_tool_install_rule= — secrets stay in
=pass=. The smoke harness reads =~/.agor/cli-token= directly so
no live =pass= lookup per run. *BUG-4 follow-up:* default seed
=admin@agor.live= / =admin= is hardcoded until rotated; filed in
=now.org= § Open follow-ups — rotate via =agor user= verb before
exposing the daemon to anything network-reachable.

* Known gotchas (verified 2026-05-06 EDT)

| Gotcha                                  | Trigger                                                | Fix / status                                                                                 |
|-----------------------------------------+--------------------------------------------------------+----------------------------------------------------------------------------------------------|
| Node TLS cert errors during =npm install= | Guix-shipped Node doesn't see system CA bundle by default | Pre-mitigated — =SSL_CERT_FILE= / =NODE_EXTRA_CA_CERTS= set in =~/.config/fish/conf.d/ssl-cert.fish=. *Did not bite* tonight. |
| =EBADENGINE= for =md-to-slack@1.1.7=    | Node 22.14 < required 22.16 (transitive dep)           | *Non-fatal warning.* Slack-gateway-only; we don't use it. Ignore unless you wire Slack later. |
| =npm install -g= EACCES on Guix prefix  | Guix's =~/.guix-profile/lib/node_modules= read-only    | Use step 2's =npm config set prefix ~/.npm-global=. Verified clean.                           |
| =@libsql/client= glibc-prebuilt mismatch | Bionic libc (termux) only                              | *N/A on Guix glibc desktop* — verified, no spoof needed. Termux only per =/tmp/agor-mobile-termux-verify-2026-05-06.org=. |
| Daemon can't bind / port already in use | Another Agor or dev server on :3030                    | =agor daemon stop= then restart; or set =AGOR_PORT=                                          |
| =agor= command not found after install  | =~/.npm-global/bin= not on PATH                        | Use the fish PATH file from step 3, then =exec fish=                                          |
| =agor init= prompt is interactive       | First boot asks /Enable auth + multiplayer?/           | =echo "n" \| agor init --force= still seeds default admin (see BUG-4)                        |
