*Expanded.* Per memory rule [Dev artifacts as app candidates],
every dev-process tool is treated as a candidate user-facing
feature. This doc is the formal application of that lens to R27.

APP-adjacent = needs UX adapter; BOTH = measurable in bench AND
ships in app; BENCH-only = pure round infra. Surfaces honor
[Keep CLI pristine] (Typer verbs co-equal), [Expand elisp

[Default browser is qutebrowser] (dashboards), and [Default
agent artifacts to .org]. FOSS-only per [FOSS models only] —
Claude appears solely as K5 sentinel role (G18, H6 reference).
