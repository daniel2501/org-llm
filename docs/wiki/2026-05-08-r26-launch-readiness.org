* Section 6: Recommended action

*Recommended sequence (after OpenRouter top-up):*

1. Top up OpenRouter to ≥$40 (recommend $50 for cushion above $40 floor + ~$15-25 round budget).
2. =bash scripts/_r26_preflight.sh= — full preflight, all 6 cat gates run live.
3. Inspect =scripts/_round26_dials_artifacts/PREFLIGHT_PASS= sentinel.
4. If PASS: launch harness (per existing convention,
   =python3 scripts/_round26_dials.py= or the launcher wrapper if/when written).
5. If FAIL: read =PREFLIGHT_FAIL= JSONL; resolve gate-by-gate.

*Optional:* set =ANTHROPIC_BUDGET_USED= env var if K5-claude-solo
should run as A/B reference (otherwise soft-skipped, which is fine
per FOSS-only routing target rule — R26 is FOSS-focused).

*NOT recommended pre-launch:* P1-7 (S1-S4 strategies) and P1-20
(self-healing daemon). Both add real surface area; deferring to
R27 keeps R26 scope tight + answers the "did P0 patches close the
R25 gaps" question without confounds.
