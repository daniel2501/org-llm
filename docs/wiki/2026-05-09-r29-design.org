* Summary

*Summary.* R29 is a /capability + correctness/ round — *not* another
stability sprint like R28. R28's harness-stability work held (5/7
strict P0 PASS + 2 honest-MIXED) so R29 can take more risk: ship 8-10
small fixes from the R28 four-agent scour (synthesis + quality-judge
+ walltime + providers + pareto) AND begin one or two narrow
capability picks (=/critic-this= verb POC for Phase 2026-05.20 — sync
verb POC, K20 v2 retrain corpus prep). Projected ~200 cells, $8-15
spend. Round-question: */do the post-scour fixes hold AND can we
begin shipping capability without breaking the verifier?/*

*Expanded.* R28 closed with G2 (K5 deprecation) tempered + G4 (K20
retrain) constrained + G5 (per-task slicing) strengthened — three
pieces of strategic guidance that gate R29's app-layer routing
changes (R28-R1..R28-R6) on R29 ship of: (a) BK verifier preservation
gate (R29-16); (b) K20 dispatcher restricted to BK + small-atomic
families (R29-15); (c) K5-vs-K6 expanded probe post-hardening
(R29-9); (d) K5 sentinel tool-surface fix (R29-17). Per [Wiki entries:
summary + expanded] every section leads with =*Summary.*= +
=*Expanded.*=. Per [All times in EST + 12h AM/PM] all times below 12h.
Per [FOSS models only] K5-Claude is sentinel-pending-verification;
never a routing target. Per [Phase references include name] all
phases include name + number. Per [Productionalize harness into app]
each R29 work-item that produces a user-facing surface is annotated
with its bench-to-app-mapping ID (R28-F*/R28-N*/R28-U*/R28-R*).

* R29 round shape

*Summary.* Capability + correctness — narrow scope on capability (one
verb POC + one corpus-prep), broad scope on correctness fixes (8-10
small ships from scour). ~200 cells, $8-15 spend, wall <60 min,
single launcher invocation with 5 active variants + K2 opt-in.

*Expanded.* Cell-budget breakdown: ~80 L1 (B1, B5, B7, B11) + ~60
L_BK (BK1-BK15) + ~10 K20 in-band (BK + small-atomic ONLY per R29-15;
no B1) + ~10 K5-claude sentinel (post-tool-surface-fix) + ~20
K2-kimi-k2.6 opt-in cells (B25/B26 elisp where K2's family lives) +
~10 K5-vs-K6 expanded probe (R29-9; gated on R29-16 verifier hardening
landing first). No B1 K20 cells = no 6×400s wall-cap waste.
