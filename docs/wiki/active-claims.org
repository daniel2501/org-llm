* Summary

*Summary.* The live state half of
[[id:03be52bf-003f-4762-a274-e7c88f97847f][coordination.org]].
Each active contributor (human or agent instance) holds at most
one =STARTED= heading under "Active claims" naming the files
they're touching, the branch, and the start time. On completion
the heading flips to =DONE= and moves to "Recently closed".
Stale claims (>4h with no commit/update) are subject to
announced reclaim.

* How to use this file

Read [[id:03be52bf-003f-4762-a274-e7c88f97847f][coordination.org]]
§ "Rule 1 — Claim before you touch" for the full protocol.
Short version: append a =STARTED= heading under "Active claims"
before your first =Edit=/=Write= call. Update or move it to
=Recently closed= when done. Don't leave silent stale entries.

This file is meant to churn. Don't worry about pretty diffs or
chronological ordering — append to the bottom; the next
=@tracker= sweep will compact.
