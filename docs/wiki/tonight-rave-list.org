* What this is

A queue of late-night-knockable items distilled from
[[file:roadmap.org][roadmap.org]], the
[[file:agent-roster.org][agent-roster classification]], the
[[file:agent-framework.org][agent-framework architecture]], and
[[file:2026-05-03-test-session.org][2026-05-03 test session findings]].
Roughly 3 weeks of one-short-night-each cadence, with cheap wins
up top so the early sessions feel productive and momentum carries
into the heavier slots later.

Each item names a phase / theme, an effort estimate (S=½ night,
M=1 night, L=2-3 nights), the load-bearing dependency, and the
yield (what gets *better* after this ships).

** TODO [#B] Beanhub + org-mode personal budget integration  :budget:

User asked 2026-05-03 (rave-coding session). Reference repos:
=~/repos/bh-gh-spcs= (Snowflake-side load procs, github
ingest, transactions_raw). Sibling =bh-gh*= repos likely hold
the GitHub-side budget feed.

Goal: a tangled database-backed personal budget surface in
org-llm — debit + credit + account transactions, live, with
the org-mode capture flow tied directly to the underlying
DB. The user's existing bean-counting infrastructure becomes a
native org-llm subsystem rather than an external tool to
context-switch into.

Implementation sketch:
- New module =org_llm/budget.py= with a =Budget= /
  =Account= / =Transaction= schema in =db.py= (or a sibling
  SQLite db at =~/.local/share/org-llm/budget.sqlite= to
  keep financial data isolated from vault data).
- Ingest path: read from beanhub's GitHub-published feed
  (the =bh-gh-spcs= ingest looks like the precedent — same
  feed format, different sink). Cron / =org-llm sync= hook
  pulls new transactions on launch.
- Tangle path: a literate-config style =budget.org= file
  with one heading per account; running =org-llm budget
  --tangle= writes the underlying DB rows. Reverse direction:
  =--detangle= regenerates the org file from the DB.
- Sidebar BUDGET card: balance per account, recent N
  transactions, top categories this month, a colour signal
  when a category is over-budget.
- MCP tools: =budget_balance(account?)=,
  =budget_transactions(since_days, account?)=,
  =budget_categories(window)=. Agents (planner, scribe) can
  reason about money the same way they reason about agenda.
- New recipe candidates: "what did I spend on X" →
  =budget_transactions= pre-fetch; "am I over budget" →
  =budget_categories= + threshold check.

Why this matters: the user's vault already tracks personal
state (routines, agenda, dailies). Money is the missing axis.
With the integration, the planner agent can answer "can I
afford this" without leaving the org-llm loop.

Effort: L (multi-night). Deps: Phase 19.1 (sync MVP) for the
auto-pull; standalone otherwise.

** TODO [#B] Weather-aware org-agenda (deferred stretch)       :weather:

User asked 2026-05-03 (rave-coding session). New phase candidate
or part of org-agenda-agent (wishlist).

Idea: agenda scan reads plans mentioned in headings + every
SCHEDULED entry with location/outdoor cues. Cross-references
against a weather feed for the relevant day; alerts when
forecast impacts the plan.

Example surfaces:
- Sidebar AGENDA card adds a `weather` row when any item the
  next 7d has rain/snow/heat/wind that crosses a threshold.
- "Hike Sunday at 9am" in dailies → check Sunday forecast →
  surface "60% chance rain Sun 9am-noon".
- "Mow lawn" / "BBQ" / "garden" / "wash car" / heading tag
  =:outdoor:= flagged as weather-sensitive.

Implementation sketch:
- New inferrer =weather_sensitive_keywords= reading recent
  agenda items + flagging the heading text against a small
  outdoor-keyword list (curated lowercase: =hike=, =bbq=,
  =garden=, =mow=, =run=, =bike=, =walk=, =fish=, =camp=,
  =beach=, =yard=, etc) plus =:outdoor:= tag.
- New MCP tool =weather_for_agenda(date_range)= calling a
  free weather API (open-meteo.com — no key, lat/lon based).
  User location resolved from =db.Config('location_lat')= /
  =('location_lon')= or via =timedatectl= geo-clue.
- Sidebar surfaces high-impact alerts; agenda agent narrates
  them in scheduled-review queries.

Effort: M-L. Deps: agenda agent (wishlist) for the narrative
