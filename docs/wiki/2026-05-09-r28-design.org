* Summary

*Summary.* R28 is a *harness stability sprint*, not a capability
round. Scope = ship the 7 P0 fixes that R27 synthesis §7 identified
(WALL_CAP enforce, K11 dispatcher-spend, Groq deny-list literal, K20
ctx-clamp + liveness re-poll, leaderboard in-flight flag, four
procedural memory-rules, =_round28_dials.py= fork) + run a *small
150-cell verification round* on R27's working subset (K1, K6, K8,
K5-claude sentinel, K20-foss-distill) — *no new variants, no new
strategies*. K11 retired per pareto §R28 implications. K2 stays
gated on Modal-Kimi billing. Projected spend $5-12 (verification,
not capability). The single round-question: *do the fixes hold?*

*Expanded.* R27 v6 (29:53 wall, 256 cells, $20.41) shipped the K1
dispatch fix (mean 4.9 → 16.7, +11.8) but exposed five race
conditions + one deploy-gap + one display bug at the harness layer.
Each is a /correctness/ defect — fixes that don't earn round
re-baseline, just stop the leaks. The R28 round itself is a
*verification harness* for those fixes: same task set as R27 minus
B13/B20/B25/B26 (didn't run R27 anyway), same variant pool minus
K11, same strategies (no S5+, no new orchestration). If R28 ships
clean, R29 — Phase 2026-05.20 sync verb POC — re-pins K20 as critic
(extended-chain gate, not mini-A/B gate) and resumes capability
work. Per [Wiki entries: summary + expanded] memory rule, every
section leads with =*Summary.*= + =*Expanded.*=. Per [Phase
references include name], phases name + number throughout. Per
[FOSS models only], K5-claude appears only as ceiling sentinel;
Groq is a deny-list reference, never a target.

* R28 round shape

*Summary.* Narrow scope: 150 cells (vs R27's 256), reuse R27's
working subset, no new variants, no new strategies, no new tasks.
Goal = "do the fixes hold?" not "extend capability." Round budget
$5-12, wall <30 min, single launcher invocation.

*Expanded.* Cell-budget breakdown: ~80 L1 (B1, B5, B7, B11) + ~50
L_BK (BK1-BK15) + ~10 K20 in-band (the cells that scored 0 in R27
must score >0 in R28) + ~10 K5-claude sentinel ceiling. No L2
prose, no L3 dial ablation (R27's L3 ran fine; not the gate). No
top-3 selector promotion of new tasks; B13/B20/B25/B26 stay absent
(R29 picks them up).
