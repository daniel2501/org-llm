* Summary

*Summary.* =scripts/agor-smoke.sh= is the first-contact harness for
[[id:1e75cdba-f743-456d-9d0f-07b9e0da33ac][multi-agent-org-llm]]: ~180 lines of bash that walk an admin JWT
through the Agor REST surface to create a worktree + parent session,
hand the per-session =mcp_token= to =claude -p= via a transient
=mcp-config=, and assert the parent spawns a child via
=mcp__agor__agor_sessions_spawn=. *Verified live* on =agor-live
v0.17.3= + =claude code 2.1.129= (2026-05-06 EDT — 12 s, $0.07).

*Expanded.* The original design assumed =anonymous-localhost=; that
path *does not exist* in =0.17.x= (=allowAnonymous=false= ships by
default). Working flow is admin-JWT-bearing throughout; the
per-session =mcp_token= is delegated only to =claude -p='s MCP
transport. Cost is bounded via =--max-budget-usd= (=--max-turns= was
removed in 2.x). Bash kept for spike speed (per *Keep CLI pristine* —
circle back as Typer verb =tracker agor-smoke= once stable).

* What the script does (verified flow)

1. *Prereqs* — =agor=, =curl=, =jq=, =python3= mandatory; =claude=
   required unless =SKIP_CLAUDE=1=.
2. *Daemon health* — =curl /health=. Daemon must already be up (we
   don't =agor daemon start= — stale-PID footgun).
3. *Auth* — read =~/.agor/cli-token=, assert =expiresAt > now=. Token
   minted by =agor login -e admin@agor.live -p $(pass
   org-llm/agor/admin-password)=. Failure prints exact re-auth cmd.
4. *Resolve repo* — =GET /repos= (no =/api= prefix); pick
   =data[0].repo_id= unless =$AGOR_REPO_ID= / =$AGOR_REPO_PATH= pin one.
5. *Create worktree* — =POST /repos/:id/worktrees= with shape
   ={name, ref, createBranch:true, sourceBranch, refType:"branch"}=.
   Daemon auto-assigns =worktree_unique_id= via
   =ReposService.createWorktree=, fire-and-forgets the executor.
6. *Create parent session* — =POST /sessions
   {worktree_id, agentic_tool:"claude-code"}=. Response includes
   =mcp_token= (snake_case! after-create hook regenerates it for any
   ≥member caller). 24 h JWT expiry by default.
7. *Write =/tmp/agor-mcp-$$.json=* — ={mcpServers:{agor:{type:"http",
   url:".../mcp", headers:{Authorization:"Bearer …"}}}}=.
8. *=claude -p= run* — =--model sonnet --output-format stream-json
   --verbose --mcp-config … --strict-mcp-config --permission-mode
   bypassPermissions --max-budget-usd $MAX_BUDGET_USD=. Prompt nudges
   the parent to call =agor_execute_tool= → =agor_sessions_spawn=
   (progressive-disclosure surface).
9. *Assert + report* — parses =CHILD_SESSION_ID= from stream,
   verifies =GET /sessions/:child= has =genealogy.parent_session_id ==
   $PARENT_SID=, prints =total_cost_usd= summed from =result= block.
10. *EXIT trap* — deletes mcp-config; archives parent (skip with
    =KEEP_DIRTY=1=).

* Bootstrap-token investigation (corrected 2026-05-06)

| Original assumption                              | Reality on agor-live v0.17.3                                |
|--------------------------------------------------+-------------------------------------------------------------|
| REST prefix =/api/=                              | None. Routes mounted at =/sessions=, =/repos=, =/worktrees= |
| Anonymous-localhost auth on fresh =agor init=    | =allowAnonymous=false=; =/health.auth.requireAuth=true=     |
| =mcpToken= (camelCase) in session response       | Field is =mcp_token= (snake_case), set by after-create hook |
| Sessions mintable without worktree               | =worktree_id= required                                      |
| =agor session create= CLI verb                   | Doesn't exist; CLI ships only =list= + =load-claude=        |

Bootstrap order on a fresh install:
=agor init= → admin user (default =admin@agor.live= / =admin= seeded
silently on first boot) → =agor login= (writes =~/.agor/cli-token=) →
register repo → =POST /repos/:id/worktrees= → =POST /sessions= →
bear =mcp_token= against =POST /mcp=.

* Known bugs in agor-live v0.17.3 (filed in test log)

1. =agor worktree add= CLI errors with =client.service(...).createWorktree
   is not a function= — Feathers REST client doesn't expose custom methods.
   Workaround: =POST /repos/:id/worktrees= directly.
2. =GET /sessions/:id/genealogy= returns 500 — handler reads
   =params.route?.id= but =params= is undefined for plain GETs.
   Workaround: read =genealogy.children= from =GET /sessions/:id=.
3. Bare =POST /worktrees= fails — =worktree_unique_id= is auto-assigned
   only inside =ReposService.createWorktree=, not at the DrizzleService
   base. The misleadingly-available =/worktrees= route inserts =null=
   and the schema rejects it.

they're each a single MCP tool call whose response shape carries the

* v0.2 — token refresh primitive

*Summary.* =scripts/agor-token-refresh.sh= refreshes a session's
=mcp_token= via the documented =GET /sessions/:id= after-get hook.
Sourceable (5 functions: =agor_decode_jwt_exp=,
=agor_token_seconds_until_expiry=, =agor_token_near_expiry=,
=agor_refresh_session_token=, =agor_refresh_if_near_expiry=) +
standalone CLI (=decode= / =seconds-left= / =check= / =refresh= /
=refresh-if-needed=). 9/9 live tests PASS on agor-live v0.17.3.
Verdict: long-lived-team cron promotion *unblocked*.

*Expanded.* Verified contract: calling =GET /sessions/:id= as the
admin who created the session returns a freshly-minted =mcp_token=
with =exp= advanced to "now + execution.mcp_token_expiration_ms"
(default 24 h). Re-mint differs from the prior token (verified — first
two test runs returned tokens with =exp= delta = wallclock delta).
The primitive exposes both a "refresh always" entry point
(=refresh_session_token=) and a "refresh if within threshold" path
(=refresh_if_near_expiry=, default 300 s) so heartbeat callers can
amortise the round-trip.

*Coverage map.*

| Function / verb              | Pass criterion                                                              | Live result      |
|------------------------------+-----------------------------------------------------------------------------+------------------|
| =decode <jwt>=               | Prints exp epoch (positive integer)                                         | PASS             |
| =seconds-left <jwt>=         | Returns ~86400 for a freshly-minted 24 h JWT                                | PASS (=86400)    |
| =check <jwt>= (default 300s) | Fresh token rc=1 + prints =OK=                                              | PASS             |
| =check <jwt> 90000=          | Fresh token rc=0 + prints =NEAR_EXPIRY= (threshold > 24 h)                  | PASS             |
| =refresh <sid>=              | Returns new JWT; =exp_new > exp_old=; new prefix differs                    | PASS (delta=2s)  |
| =refresh-if-needed= (300s)   | Fresh token returns unchanged                                               | PASS             |
| =refresh-if-needed= (90000s) | Forces refresh; new exp ≥ prior                                             | PASS             |
| Bogus session id             | Exit 30 NOTFOUND (with v0.17.3 500-quirk handling — see bug #9)             | PASS             |
| Missing =cli-token= file     | Exit 20 AUTH                                                                | PASS             |

*Run.*

#+begin_src sh
# Decode an arbitrary mcp_token's exp claim
scripts/agor-token-refresh.sh decode "$JWT"

# How long until this token expires?
scripts/agor-token-refresh.sh seconds-left "$JWT"

# Refresh always — sized for "every heartbeat"
NEW=$(scripts/agor-token-refresh.sh refresh "$SESSION_ID")

# Refresh only if within 5 min of expiry — sized for "every long tick"
NEW=$(scripts/agor-token-refresh.sh refresh-if-needed "$SESSION_ID" "$CURRENT_JWT" 300)

# Sourceable — for in-script use
. scripts/agor-token-refresh.sh
fresh=$(agor_refresh_if_near_expiry "$SID" "$current" 300)
#+end_src

* Long-lived sessions — token refresh

*Summary.* =scripts/agor-mcp-refresh.sh= rotates the bearer in a
=/tmp/agor-mcp-<sid>.json= before its JWT =exp= lapses, so a
heartbeat-driven team session can outlive the default ~24 h
=mcp_token= TTL without manual intervention. Companion to
=agor-smoke.sh=; same admin-JWT + REST conventions; pytest harness at
=tests/test_agor_mcp_refresh.py= (8/8 PASS, 2026-05-06 EDT).

*Expanded.* The smoke harness writes its mcp-config once at session
boot. For one-shot runs that's fine. Long-lived teams (per
[[id:1e75cdba-f743-456d-9d0f-07b9e0da33ac][multi-agent-org-llm.org § Coordination patterns]]) need rotation:
the script base64url-decodes the bearer's JWT payload, compares =.exp=
against =now + ttl-buffer= (default 600 s), and on staleness
=GET /sessions/:id= for a fresh =mcp_token=, then atomically rewrites
the config (=jq= → =<path>.tmp.<pid>= → =mv=) preserving every
sibling field. Re-login to admin only happens when
=~/.agor/cli-token.expiresAt= is in the past (uses =pass
org-llm/agor/admin-password= under the hood — same creds path as
=agor-smoke.sh=). The =GET /sessions/:id= path is preferred over
re-login because the per-session token is regenerated by the daemon's
after-create hook for any ≥member caller.

*Cron / supervisor recipe.*

#+begin_src sh
# Every 5 min while a long-lived team session is active. Refreshes
# only when the bearer has < 600s left; exits 0 quickly otherwise.
*/5 * * * * /home/daniel/repos/org-llm/scripts/agor-mcp-refresh.sh \
    --config /tmp/agor-mcp-<sid>.json \
    --session-id <sid> \
    --ttl-buffer 600 >>/tmp/agor-refresh.log 2>&1

# Probe-only: print "EXPIRES_IN <sec>" without touching the file.
scripts/agor-mcp-refresh.sh --config /tmp/agor-mcp-<sid>.json \
    --session-id <sid> --check-only
#+end_src

*Exit codes.* =0= refreshed (or skipped fresh); =10= PREREQ; =11=
AUTH (admin JWT bad); =12= SESSION_GONE (404 / archived); =13=
CONFIG_BAD (malformed JSON / non-JWT bearer); =14= WRITE_FAIL.

*v0.2 gap.* =claude -p= reads =--mcp-config= at startup, so flipping
the file is necessary but not sufficient — the supervisor still must
restart the agent (or upstream Claude Code must learn
MCP =notifications/tools/list_changed=). =--pid= triggers a
best-effort =SIGHUP=, which most clients ignore today; documented as
a hook for when they don't.
