  page summarises the in-flight slice.

Use case: open this when you want one screen showing "what did
I do this week + what's the queue". Open the tracker when you
want filterable agenda views by tag / state / priority.

* Update protocol

This page is *always* stale relative to git. Refresh after
each significant work block:

1. Update the *Recently done* table from =git log --oneline=
   (last ~10-20 commits). Drop entries older than ~2 weeks.
2. Update the *Ahead* table from
   [[id:9096622a-689c-4bb1-8e32-1654bce48d1c][dev-tracker.org]]'s
   scheduled TODOs (this week + ~next 2 weeks).
3. Update the *Standing* table when long-running STARTED items
   change state.
4. Bump the *As of* line at the top of each section so readers
   can see when the snapshot was taken.

No automation yet — manual refresh. A future =org-llm tracker
snapshot= verb could regenerate this page from
=dev-tracker.org='s state if it earns its keep.
