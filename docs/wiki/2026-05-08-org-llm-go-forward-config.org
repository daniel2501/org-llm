* Executive summary

*Headline.* After 25 rounds of bench (R1-R25), ~1208 cells, and
~$100-110 in cumulative spend, =org-llm= can reliably operate on
FOSS models at *59× lower cost-per-quality-unit than Claude on the
matched layer1 slice*. The default scribe is K1-qwen30 (Qwen3-Coder-
30B-A3B-Instruct) at $0.00057/qpt, served via OpenRouter (Novita
preferred). K2-kimi-k2.6 is the high-stakes prose specialist;
K11-qwen3coder is the elisp specialist with budget cap; K8-deepseekV3
is the *confirmed second frontier point* (R25 $0.00069/qpt). K6-
llama70b and K7-qwen72b are dropped from production. K5-claude-solo
remains as a sentinel-only quality ceiling.

*Top 5 recommendations.*

1. *Default LLM = K1-qwen30 via OpenRouter Novita.* 6 of 6 rounds
   on the FOSS Pareto frontier; $0.00057/qpt at n=50 in R25.

2. *Frontier is now K1+K8 (two-wide), not K1-only.* R25 confirmed
   K8-deepseekV3 at $0.00069/qpt as the durable second seat —
   indistinguishable from K1 on cost-per-quality. K8 is the
   recovered all-purpose backup, not just a B1-only artifact.

3. *Claude moat is 59× when sliced like-for-like, not 48× R24.*
   Headline R25 ratio of 22× is layer-mix artifact (K5 ran more
   layer_bk + layer2 cells where Claude scores higher per dollar).
   On matched layer1, FOSS pulled further ahead.

4. *3 of 11 R25 patches were ineffective — verification gap.* K2
   max_tokens=4096 cap was dead code (constant defined, never
   threaded into SpecialistTask); WALL_CAP fired the kill log
   but ThreadPoolExecutor shim blocked outer worker until inner
   thread finished; top-3 selector picked individual cells (all
   K1) instead of distinct variants. R26 must add a verification
   step on every patch.

5. *K20 LoRA endpoint deploy still blocked.* Together fine-tuning
   works flawlessly; hosted serverless endpoint deploy errors out.
   R26 needs dedicated H100 endpoint (~$5.49/hr) with
   =min_replicas=1= — no scale-to-zero for fine-tuned models.

*Ongoing.* K20-foss-distill LoRA training completed on Together
(~$5, 10 min); endpoint deploy still blocked → R26 dedicated H100.

** Self-hosted vLLM (R26 work)

For K1 + K2, deploy dedicated vLLM endpoints on RunPod or Together:
- Eliminates broker tool-format quirks (R19 K8 collapse cause)
- Removes OR rate cap risk (R21-R23 402 cause)
- Sub-second TTFT vs 800ms-2s OR (Sp3 from walltime agent)
- Cost: $40-60/round at A100 80GB SXM, $0/round at idle
  (autoscale to 0 between rounds)

*RunPod caveat:* dockerArgs unreliable per PM2; use pre-baked
Docker image with =ENTRYPOINT= set. Don't pass training/serving
script via API.

*Together caveat:* fine-tuning works flawlessly; serving needs
dedicated endpoint with `min_replicas=1` (no scale-to-zero
serverless for fine-tuned models).

** R26 critical patches (verification gap from R25)

Three R25 patches were *labelled-but-not-effective*; R26 must wire
them properly with a verification step:

| Bug                                  | R25 state             | R26 fix                                        |
|--------------------------------------+-----------------------+------------------------------------------------|
| =count_bracket_errors= cross-line FP | Per-line nested fixed | Mirror per-line walker into =count_bracket_errors= (single-file patch to =scripts/quality_lint.py=) |
| Top-3 selector = cells, not variants | All 3 collapsed to K1 | Aggregate by variant first, rank by per-cell mean (not sum), take top-3 distinct |
| WALL_CAP = label only                | =ThreadPoolExecutor= shim blocks outer worker | Replace with =multiprocessing.Process= (terminate-able) OR =threading.Event= polled by =run_one_cell= to abort in-flight HTTP |
| K2 max_tokens=4096 dead code         | Constant defined, never threaded | Add =max_tokens: Optional[int]= to =SpecialistTask=, thread through =_chat_completions=, read =_R25_VARIANT_MAX_TOKENS= in =run_specialist_for_cell= |

*Why critical.* All four bugs distorted R25 results: 5 floor-drops
were FP-1 (not real defects); Layer-2/3/BK collapsed to K1 only
because the selector deduped wrong; 16 K2/B1 cells ran 455-1697s
past the 400s cap; K2 produced 22-28k char outputs at the 8000
default ceiling. Fixing these first means every subsequent round
measures something real. *Acceptance criteria*: re-run on saved
diffs; K11/K17/K8 lint collapses to 1.0/cell; top-3 returns 3
distinct variants; L1 wall lands ≤650s; K2 output chars ≤14k.
