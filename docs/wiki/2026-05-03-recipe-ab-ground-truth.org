* What this is

Hand-computed factual ground truth for the prompt set in
=scripts/recipe_ab_harness.py=, captured 2026-05-03 against this
user's vault (~572 files, 138 dailies, 182k nodes).

The judge in =scripts/recipe_ab_judge.py= parses the =:GT:= block
under each prompt heading and feeds it to Claude Opus alongside
the two narrations so factual accuracy can be graded without the
judge having to re-derive the data.

The values below were computed by directly invoking the same
=org_tools= / =vault_facts= helpers the agents would call. Where a
recipe runner already gives a trace, that trace is the ground
truth (e.g. =count_across_vault= → =total_hits=).

* Buckets

- *anchor* — recipe-eligible. Recipes are designed to win here.
- *control* — no recipe matches. Toggle should be a no-op.
- *bait*   — recipe matches but the user's intent diverges; tests
  whether the recipe path produces a misleading answer.

* Decision bar (committed before running)

For the *anchor* bucket all three must hold:
- p50 latency: =recipes_on= ≥ 30% faster than =recipes_off=
- median total tokens: =recipes_on= uses ≥ 20% fewer tokens
- judge quality: prefers =recipes_on= in ≥ 55% of pairs

For the *control* bucket:
- judge prefers =recipes_off= in ≤ 55% of pairs (no regression)

The *bait* bucket is informational — it shows whether false-fires
cause measurable quality harm even when they don't fail the bar.

If anchor clears all three AND control is safe → keep, expand
catalog. If anchor clears 2-of-3 → narrow catalog to the recipes
that individually clear the bar (per-recipe table in the summary).
If anchor clears 0-1 → dump.
