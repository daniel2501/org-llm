* New "ambitious" strategies (S21-S32) — think-big additions

** Tier-S (highest leverage)

| ID | Strategy | Mechanism |
|----+----------+-----------|
| *S21* | *Claude-distillation LoRA* | Capture Claude's R15+R16+R17 outputs as teacher signal. Train K1-qwen30 LoRA via knowledge distillation (KL loss vs Claude logits if accessible, else SFT on Claude completions). One-shot LoRA $13-22; could close Claude gap entirely. |

| *S24* | *Iterative refinement chain* | Model 1 (factual draft) → Model 2 (structural critique + revise) → Model 3 (stylistic polish). Each adds a quality dimension. |
| *S25* | *Constitutional AI for FOSS* | Self-critique loop with explicit principles: "Did you follow Rule 2b? Did you preserve all existing content? Did you generate a real UUID?" Model self-corrects based on principles. |
