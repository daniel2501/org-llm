* Summary

*Summary.* Synthesized from R15+R16+R17 findings + 4-agent R17 scour
+ spend-headroom analysis: 10 new test types + 20 new FOSS-empowerment
strategies for R18, ranked by leverage. With 23-33× spend headroom
before reaching Claude per-quality cost, R18 should be ambitious —
not minimal. Top picks for R18 v1 launch: Tier-S strategies (S1-S5)
+ Tier-S tests (T1-T4) cover the bulk of expected lift; the rest
populate R18.5 / R19.

*Expanded.* R17 closed the FOSS-vs-Claude gap to 1pt of 25 (Claude
20.1 vs K1 19.0 + K8 18.6). The remaining levers are mostly orchestration
+ specialty routing, not raw model power. R18 design absorbs these
plus the must-fix infrastructure gotchas (worktree mutex, provider
failover, fail-edit-streak abort, etc.).

* Tier-S strategy details (R18 launch)

** S1 — Hedged-strong execution

#+begin_src python
def run_with_escalation(task, dial):
    # Run cheap variant first
    result = run_cell(K8, task, dial)
    if score_cell(result) >= QUALITY_THRESHOLD:
        return result
    # Escalate to premium
    log(f"escalating to K11 — K8 scored {score_cell(result)}")
    return run_cell(K11, task, dial)
#+end_src

Threshold: median R17 quality (~17/25). K8 at $0.0005/u; if escalates,
K11 at $0.025/u kicks in. Average per-cell cost stays < $0.005.

** S2 — Best-of-N voting

#+begin_src python
def run_best_of_n(task, dial, n=5, model=K8):
    results = [run_cell(model, task, dial) for _ in range(n)]
    # Pick by cell quality score
    return max(results, key=score_cell)
#+end_src

Trivial cost: $0.025/cell with K8. Use for prose tasks where quality
matters most (B11 DEC, B5 rewrite, B20 Summary).

** S3 — Critique-then-revise

#+begin_src python
def run_critique_revise(task, dial):
    draft = run_cell(K1, task, dial)
    critique = run_cell(K2, {**task,
        "instruction": f"Critique this draft: {draft.text_output}"}, dial)
    final = run_cell(K1, {**task,
        "instruction": f"{task.instruction}\n\nCritique to address: {critique.text_output}"},
        dial)
    return final
#+end_src

3 cells per logical task. Cost ~$0.02 vs K11's $0.07. Quality should
match or beat K11 per claude-shape agent's "5 small habits stacked."

* Tier-S test details (R18 launch)

** T1 — Failure-injection

Synthetic faults to verify R18 reliability:

| Fault | Injected via | Expected behavior |
|-------+--------------+-------------------|
| TCP drop mid-stream | mock urllib.request that raises =IncompleteRead= at iter N | Hedged retry on alternate provider succeeds |
| Worktree race | spawn 8 simultaneous git worktree adds | Mutex serializes; no collision |
| Malformed prefetch | inject random JSON corruption | Cell fails gracefully with =prefetch_invalid= error |
| Partial provider unavail | block one provider's IP | Failover chain kicks in |
| Token exhaustion | =max_budget_usd=0.001= | =budget_exceeded= terminal state |
| Scope strict bypass | model attempts =../../etc/foo= | Refused, no file access |
