* Summary

*Summary.* The /annual-review team/ is a *long-lived* team under
[[id:1e75cdba-f743-456d-9d0f-07b9e0da33ac][multi-agent-org-llm]]: =@atoz= pulls the year-arc (org-roam nodes,
tags, concept additions); =@geordi= computes longitudinal drift
metrics (mood trend, topic distribution, productivity arc) over the
dbt pipeline; =@data= drafts the narrative review tying observations
together. Cron-fires every January 1 (00:01 EST), or on user-invoked
month-boundary for partial-year reviews. The same roster runs each
year; this is the *anti-mediocre-year primitive* — surfaces drift
before it crystallizes.

*Expanded.* Most "year in review" tools are summary engines —
they tell you what /happened/. The annual-review team is a /drift
detector/: it surfaces patterns the user wouldn't see by scrolling
their journal. The three-role shape forces the team off summary-
mode and into interpretation-mode: =@atoz='s structural pull
(/what concepts entered the vault?/) + =@geordi='s metric pull
(/which directions trended?/) + =@data='s synthesis (/where is the
arc bending, and is that the bend you want?/). The team is
long-lived /not/ because it runs continuously, but because the
roster + toolset + memory persist across years — Year N's review
references Year N-1's narrative, gradually building a lineage the
user can re-read.

* Tick-by-tick

*Setup* (T0): captain reads previous year's review (if exists) — establishes lineage continuity per the long-lived team's persistent memory.

*Pull phase* (parallel sibling spawns):

1. =@atoz= queries org-roam: nodes created in window, tag deltas (new tags, retired tags), concept additions to wiki, cross-link density change
2. =@geordi= runs longitudinal SQL: mood-trend dbt model, topic distribution by quarter, productivity arc (commits + clocked hours by week), theme drift (which agents got called most often)

*Synthesis phase*: captain narrates one turn, integrating both pulls + last year's review. =@data= drafts the prose narrative under =* Year N review= heading; cross-links to source nodes; flags drift signals as tracker entries.

*Closeout*: review committed to =~/org/annual-review-{year}.org=; =kind=team-session= entry to captain's log; previous year's =memory/{date}.md= per-agent notes archived as priors for next cycle.

* Evolution

- *Toolset adapts every year.* First runs lean on raw counts; subsequent years promote the recurring metrics (e.g. "topic-shift detector") to first-class dbt models per Phase 2026-05.20 — sync verb POC — self-coded tools.
- *Pace metrics widen.* Year 1 might track only commits + journal entries. Year 3 might include sleep, workout, finance, GPS-derived movement patterns — every life domain that landed under [[id:b537c80a-4451-4d5e-a191-6769e86a93f9][life-as-code.org]] is a candidate column.
- *Review template hardens.* The narrative shape (intro / arc / drift / asks-of-Year-N+1) stabilises; later runs use it as a literate template rather than re-deriving.
- *Lineage compounds.* Year 5's review references Year 1's "asks of Year 2" + answers them — the team becomes the user's longitudinal mirror.

* Failure modes

| Mode                                       | Likely cause                                       | Mitigation                                       |
|--------------------------------------------+----------------------------------------------------+--------------------------------------------------|
| Cron didn't fire on Jan 1                  | Daemon down / 24 h JWT expired                     | Token-refresh primitive (landed); =org-llm doctor= weekly |
| Pull returned empty (no nodes in window)   | Vault relocated, indexer broken                    | Pre-fetch fails LOUD; captain refuses to narrate |
| Drift signal is noise, not signal          | Single-year sample size                            | Year ≥ 2: cross-reference against prior; Year 1: flagged-not-acted |
| Review reads "summary" not "interpretation" | Captain prompt drifted toward stat-dump            | Manager pre-fetch + agent narrates pattern (per memory =feedback_manager_prefetch_pattern=) |
| =:PRIVATE:= material leaks into review     | Year-arc pull doesn't honor tag                    | =@atoz= filters =:PRIVATE:= at query time        |
| Cron fires while user is asleep            | Naive cron without quiet-hours awareness           | =1 0 1 1 *= = 00:01 EST; review available on wake |
