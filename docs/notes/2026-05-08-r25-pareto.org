* Summary

*Summary.* R25 ran 189 cells / *$9.67 spent* / 38 min wall across
9 variants (incl. K33/K34/K35 large-FOSS ceiling probes). *K1-qwen30
holds the floor at $0.00057/qpt layer1-only* -- 6 rounds confirmed
($0.0005 / 0.0006 / 0.0008 / -- / 0.00047 / -- / 0.00054 / 0.00057).
*K8-deepseekV3 generalizes onto frontier at $0.00069/qpt layer1-only*
(R20 0.00092, R24 0.00090) -- the durable-frontier story is now two
points wide, not one. *Large-FOSS ceiling probes failed*: K33-qwen3-
coder-72b cost $0.05904/qpt (100x K1, 2x K11), K34-deepseek-v3-pro
+ K35-llama-3.1-405b returned silent_noop on their single cells
(score=0, specialist_cost=$0). *Claude moat shrunk 48x -> 22x* but
not because K5 got cheaper -- *K1's $/qpt slipped slightly* AND K5
ran a different layer mix this round.

*Expanded.* The R24 frontier was three-wide (K1+K8+K6); R25 is
two-wide (K1+K8) because K6-llama70b was dropped from the baseline
this round and K17 stayed dominated. R25's headline finding is the
*large-FOSS-doesn't-pay verdict*: 2.4x more params (K33 vs K1) does
not buy 2.4x quality even when it works -- K33 scored 12 on its
single cell (K1 layer1 q/cell = 8.02), so the quality lift is *real
but tiny*, while the cost lift is *100x*. K34/K35 didn't even fire
output. The Claude-moat shrinkage is partly real (K1 drift +6% per-
qpt) and partly mix-effect (K5 ran 5x layer1 + 4x layer2 + 5x
layer_bk, where layer2 + layer_bk are *cheaper per qpt for K5*
because Claude scores higher there). *R26 advisory: drop K34/K35
entirely; defer K33 to a single n=5 B7-only re-probe behind a
smoke-preflight gate.*

* Section 3 -- Large-FOSS verdict (K33/K34/K35)

*Summary.* All three large-FOSS ceiling probes failed in different
ways: K33 *worked but uncompetitively* ($0.71 for score=12, 100x
K1), K34 + K35 *returned silent_noop* (specialist_cost=$0,
score=0, 1 cell each). The R25 design hypothesis "more params ->
better quality enough to justify cost" is *falsified for these
three brokers/models*; the reverse Chinchilla / smaller-better-
fine-tuned story keeps holding.

*Expanded.* Failure modes by variant:

| variant              | broker (R25) | specialist_cost | wall    | failure mode                              |
|----------------------+--------------+-----------------+---------+-------------------------------------------|
| K33-qwen3-coder-72b  | Together     | $0.7080         |  108.5s | works but 100x K1 $/qpt; 1.5x K1 q/cell   |
| K34-deepseek-v3-pro  | OR default   | $0.0000         |   17.6s | silent_noop -- no specialist output       |
| K35-llama-3.1-405b   | Together     | $0.0000         |   10.6s | silent_noop -- echoes R16 K12 405B fail   |

*K33 cost story.* Together-routed Qwen3-Coder-72B priced at ~$0.71
per cell for one B1 cell with score=12 -- compare K1 q/cell=8.02,
K11 q/cell=12.9, K17 q/cell=11.9. *72B param count buys +50%
quality over K1 for 100x cost.* The promotion gate (B7 +3 vs K1
per =go-forward-config=) was set on B1; B1 margin (+4) is wiped
out by cost.

*K34 + K35 silent_noop.* Both cells: =specialist_cost_usd=0=,
=score=0=, phase1 manager cost intact ($0.0005). Phase1 fires
(plan), specialist returns no output, no spend. Same pattern as
R16 K12 (=llama-3.1-405b-instruct=, "0 score, silent_noop"). K34
has no =BROKER_PREFS= entry -> OpenRouter default routing has no
working provider; K35's explicit =Together= route still hit
silent_noop. K33 is broker-stable but cost-uncompetitive; K34 +
K35 are broker-unstable.

* Section 4 -- Why did the Claude moat shrink?

*Summary.* R24 moat 48x -> R25 moat 22x *is real on the headline
ratio* but *mostly mix-driven, not Claude getting cheaper*. K1's
$/qpt drifted slightly worse (+6%, $0.00054 -> $0.00057 layer1-
only); K5 ran a *cheaper layer mix this round* because layer_bk
+ layer2 score higher per dollar for Claude than for FOSS.

*Expanded.* Decomposition of the 48x -> 22x shift:

| factor                        | R24 value | R25 value | direction         |
|-------------------------------+-----------+-----------+-------------------|
| K1 layer1 $/qpt               | 0.00054   | 0.00057   | +6% worse FOSS    |
| K5 aggregate $/qpt (mix-vary) | 0.02569   | 0.01453   | -43% K5 mix-cheap |
| K5 layer1-matched $/qpt       | 0.02569   | 0.03368   | +31% worse Claude |
| Apparent moat                 | 48x       | 22x       | shrunk            |
| *Layer1-matched moat*         | *48x*     | *59x*     | *grew*            |

*The headline shrinkage is a layer-mix artifact.* K5 R25 ran
5x layer1 + 4x layer2 + 5x layer_bk; layer_bk + layer2 cells
score *higher per dollar* for Claude (long-horizon BK rewards
Claude's prose density). That layer mix lowers K5's aggregate
$/qpt to $0.0145 -- nothing to do with FOSS pricing. *On the
matched layer1-only slice, moat grew to ~59x.* K1's drift
(0.00054 -> 0.00057) is within-noise: 6 readings cluster in
[0.00045, 0.0008].

* Section 6 -- R26 advisory: drop large-FOSS or probe again?

*Summary.* *Drop K34 + K35 entirely.* Defer K33 to a *single n=5
B7-only re-probe behind a smoke-preflight gate*. Do not retry K34
+ K35 at different brokers without first confirming a working route
in a 1-cell sentinel; OpenRouter has no working provider for these
two model IDs as of R25.

*Expanded.* Three options considered, scored against the project's
three quality gates (good at job / not too complex / manages
required complexity).

| option                   | good-at-job | low-complex | mgmt-complex | verdict     |
|--------------------------+-------------+-------------+--------------+-------------|
| A: drop large-FOSS all   | yes         | yes         | yes          | safe but    |
|                          |             |             |              | leaves Q3   |
|                          |             |             |              | unanswered  |
| B: re-broker K34/K35     | partial     | no          | no           | high cost   |
|                          |             |             |              | low expected|
|                          |             |             |              | yield       |
| *C: K33 B7 only*         | *yes*       | *yes*       | *yes*        | *recommend* |

*Concrete R26 K33 contingency (Option C).* 5 B7 cells (code_edit
-- the task where K33 was *designed* to ceiling-test K1). Gate:
if mean K33 score is not >=3 q-points above K1's B7 mean, *skip
K33 in R27*. Hard cost cap $4 (one cell at ~$0.71). B7 is the
only task where the larger-coder hypothesis has a credible
mechanism; B1 already showed K33 doesn't earn its premium on
prose-edit. K34 + K35 stay dropped -- broker-unstable, no path
to working route in R25's evidence.
