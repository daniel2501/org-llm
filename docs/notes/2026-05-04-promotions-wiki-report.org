* Decisions

- *Section ordering.* What this is → Promotions → SSSS →
  Threshold → Literate config trio → Overlap audit → Risks →
  Concrete first slice → See also. Two mechanisms first
  (so the reader gets the load-bearing pair before the
  scaffolding), then the hard part (thresholds), then the
  user-touchable layer (literate config), then the comparison
  / risk / status passes that close out concept pages in this
  wiki.
- *SSSS as sibling, not sub-bullet.* Per the brief — a peer
  H1 to Promotions, not nested under it.
- *Worked example trimmed.* The dashboard case originally
  had four bulleted phrasings; collapsed to inline parens to
  hit the ~250 line target without losing the punchline.
- *No filenames for the LOG slice.* Brief said the parallel
  agent owns the names; the page refers to "the LOG layer
  (in progress)", "the DB-side notice table", "the writer
  API" without naming files or columns.
- *Threshold defaults.* Picked first-cut numbers (N=4 / 7d /
  ≥10s mean cloud time / cosine ≥0.82) and labelled them
  guesses, with the LOG-layer-evidence loop as the path to
  re-tune. Rather than leave them un-specified.
- *Overlap audit.* Kept all four comparisons from the brief
  (curator, agentsmith, insight cards, recipes); each
  trimmed to 2–3 sentences after a length pass.
- *@data-analyst as the canonical builder.* Used as the
  worked-example dispatch target throughout. The brief named
  it once; I propagated it without inventing it as a wiki
  entry. It does NOT yet exist in =agents.org= /
  =agent-roster.org= — see open question below.

   speculative?
2. *Phase 29 sub-phase placement.* The page positions
   promotions + SSSS as filling Phase 29's "who notices"
   gap, but doesn't propose new sub-phase numbers (29.4 /
   29.5?). Brief was silent; I left numbering to whoever
   updates the roadmap. Should the roadmap entry get a
   "Promotions / SSSS slot" cross-reference?
3. *Threshold defaults are guesses.* N=4, 7d, 10s, cosine
   0.82 are reasonable but unjustified. If you have a
   stronger prior, swap them in. The LOG-layer-first plan
   is the actual answer to "we don't know yet."

   can graduate into shared recipes" but doesn't define the
   bar (analogue to recipes' ≥55% A/B win rate). Worth
   spelling out, or wait until we have one to graduate?
