* Summary

*Summary.* Across R15-R19 the only truly stable variant is
=K5-claude-solo= (CV=0.20, mean 11.3 mech) — every FOSS variant moved
20+ score points round-to-round, driven by harness changes (R17
append-only shim, R18 worktree-concurrency disaster, R19 worktree fix
+ scoring-rubric improvements) more than model behavior. R19 vindicated
the R18-quality-judge thesis: =K1-qwen30= became the FOSS leader (mean
22.1, $/u=0.0005, 28 cells, top mech 47), and three previously
under-tested FOSS variants (=K11-qwen3coder=, =K17-glm46=,
=K2-kimi-k2.6=) clustered with it inside one score band. The mech
score gap between K1 and K5 has reversed: K1's R19 mean (22.1) now
exceeds K5's (14.8), confirming that the R15-R17 "Claude ceiling"
narrative was an artifact of mech-scoring rules that quietly punished
FOSS abstention/append patterns.

*Expanded.* Cross-round signal stability is dominated by *harness
deltas*, not model deltas — R18's collapse (mean 2.5, 90/140 worktree
errors) plus R19's recovery (mean 15.3, 12/120 errors) prove the
benchmark is currently a harness benchmark. R15-R17 each had a
different "winner" (K1, K7, K11) because each round shipped a different
scoring rule (destructive-edit reward, append-only shim, then dial
sweep). Only R18->R19 shows what looks like a *clean inter-round
signal*: identical 10-variant pool, dial-sweep stable, fixed harness.
On that read: K1/K11/K17/K2 are an interchangeable FOSS quartet at
~$0.001-0.01/u; K7/K6 are the bracket-disaster tier; K8 is the
cheap-floor; K5 is the quality-ceiling baseline used for blind judging.
R20+ should *freeze the harness* for two consecutive rounds before
declaring any variant winner real.

*Reading.* K5's CV=0.20 is the only number that says "this variant's
quality is independent of harness state". Every FOSS variant has
CV>=0.33; the high-CV cluster (K1/K2/K11/K17 at 0.65-0.86) is the
group whose round-to-round mean *changed by 2-10x*. This means the
benchmark currently measures "how friendly was this round's scoring
rubric to FOSS abstention + append-only behavior" more than "how good
is the model".

** Per-round narrative

- *R16:* K7 +4.4 (destructive B11 wipe rewarded by mech score). All
  others +/-3.
- *R17:* K7 -12.1 (append-only shim corrected R16 inflation +
  DeepInfra =IncompleteRead=). K1 -3.7 from same shim. Others flat.
- *R18:* universal -3 to -8 — the 90/140 worktree-concurrency errors
  flooded the cell pool with score=0 entries; not a model regression.
- *R19:* big jumps (+11 to +23) for the FOSS quartet K1/K2/K11/K17
  driven by (a) worktree-mutex fix dropping err to 12/120 and (b)
  scoring rubric folding in cleaner abstention recognition. K5 only
  +7 because its R18 baseline was already partially insulated from
  the worktree collapse.

** Heatmap reading

- *Wrap-cross-link tasks (B1):* unstable winner (K1, K7, K1+K11, K7,
  K1). R19 K1 verdict aligns with R17 K1 verdict (the two cleanest
  rounds); R16/R18 K7 wins were destructive-edit / worktree-noise
  artifacts. *K1 is the real B1 owner.*
- *Table edits (B5):* K5 won R17/R18/R19 — three consecutive
  harness-versions agree. K5 is the right B5 router target. R19's
  layer2 only had K1+K5 so this is partly forced, but R18 had four
  variants and K5 still won.
- *Doc-noise no-op (B7):* tie@0 in 3 of 5 rounds — the spec is a no-op
  trap; mech score 0 is the *correct* answer. K7 R15/R16 wins were
  destructive false positives. K1 R18 win is a false positive
  (unreachable code per R18 quality-judge).
- *DEC append (B11):* migrated from K1+K2 (destructive R15/R16) to K5
  (clean append, R17/R18/R19). *K5 is the only confirmed-good B11
  router target on the FOSS-allowed list; K1/K11 are second tier.*
- *LICENSE bump (B13):* trivially-tied — every variant produces the
  same 1-line diff. Use cheapest available variant (K8 or K1).
- *No-op trap (B20):* never has a non-tie winner. Any variant that
  abstains is correct; reward must come from rubric not score.
- *defcustom edit (B25):* migrated K2 -> K11 -> K1, but R18+R19 both
  K1. Stable for 2 rounds. *K1 is the B25 router target.*
- *defun add (B26):* always 4-way tied at 5; use K1 (cheapest).

** Concrete R20+ rules

1. *Default scribe = K1-qwen30* — mean 22.1 at $0.0005/u; 48-fold
   cheaper than K5 per quality unit. Promote to org-llm production
   default once R20 confirms R19's signal.
2. *Quality ceiling = K5-claude-solo (judge / sentinel only)* —
   FOSS-only rule blocks production scribe. Keep for blind Opus-judge
   pairing; mean 14.8 at $0.0242/u.
3. *Three-way FOSS jury for ambiguous tasks* — K1 + K11 + K17 (or
   K2). All clustered at 21-23 mean in R19; majority vote on disagree.
   Total $/u ~$0.017.
4. *Drop K6-llama70b + K9-mixtral* — both <6 mean, not stable, no
   strength niche. K6 fails non-destructively (silent_noop) which is
   harmless but adds zero. K9 is provider-expensive without quality.
5. *Gate K7-qwen72b behind bracket-validator* — R18-quality-judge
   identified K7 as broken-bracket-prone. R19 mean 10.8 looks fine but
   the bracket failures may be hidden by current rubric. Require a
   post-edit org-mode parse before accepting K7 output.
6. *Use K8-deepseekV3 for trivial-edit tasks* (B13/B20/B26-class
   1-liners) — cheapest viable; quality irrelevant when output is
   0-2 line diff.
7. *FREEZE THE HARNESS for R20-R21* before any further routing
   decisions. The R15->R19 churn proves cross-round comparison is
   currently noise-dominated. Two consecutive rounds with identical
   scoring + identical worktree infra would let us read real model
   trajectory.
8. *Add a worktree-fix regression test* — R18's 90/140 collapse must
   not recur. The R19 fix (filesystem mutex per quality-judge) is in
   prod but not tested.

* 6. Open questions for R20

- *Is K1's R19 spike real?* — replicate R19 with no harness changes.
  If K1 stays at ~22 mean, promote to default scribe. If it drops
  back to ~7 (R17-equivalent), the jump is rubric-sensitive.
- *K11/K17/K2 cluster — interchangeable or task-specialized?* — R19
  data is too small per-task (10 cells each) to differentiate. R20
  needs a per-task break-out for the FOSS quartet.
- *K5 reflects production behavior, or routing-noise?* — K5 mean
  dropped 11.3 -> 14.8 across rounds, which looks stable, but its sd
  is 13.4 in R19. The bimodal pattern (50 on hits, 0 on no-ops)
  inflates sd. Need quality-judge re-rank to confirm.
