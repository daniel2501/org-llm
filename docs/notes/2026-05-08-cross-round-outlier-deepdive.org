* Cross-cutting — patterns common to *best* cells

*Summary.* Five repeatable traits across all 5 rounds.

*Expanded.*

1. *Prefetch payload with canonical IDs is load-bearing.* Every
   high-quality B1/B11 cell used the manager's =known_ids= list
   (R15 K1: 99 IDs available, 7 used). =bt_pi= (inlined prefetch)
   and =bt_pt= (tool-only prefetch) both produced systematic 0s.
2. *=bt_pb_m1_tb_s1= dial dominates.* Every top-cell row above is
   on this dial. =tm= (minimal tools) and =m0= (no manager) produce
   non-zero best cells but with measurable degradation.
3. *Append-only beats re-wrap on long files.* K5 R17/R18/R19 B11
   always appends at EOF (line 1637+/1652+); K1/K7 R16 B11 used
   =edit_file old/new= to *replace* DEC-019 and got destructive diffs.
4. *File <300 lines correlates with success.* B1 (324 lines), B25
   (new ~12-line elisp), B26 (5-line defcustom add) produce most
   top-3 cells. B11 (~1600-line decisions.org) only succeeds
   under append-only enforcement.
5. *Models: K1-qwen30 + K5-claude + K8-deepseekV3 only.* K1 = cost
   pareto, K5 = quality ceiling, K8 = cheap floor with respectable
   quality. K11-qwen3coder is third FOSS choice with a 50-240x cost
   penalty.

* Cross-cutting — patterns common to *worst* cells

*Summary.* Five failure shapes; first four are model defects, fifth
is harness/provider.

*Expanded.*

1. *Whole-section overwrite on B11 (R16).* K1 + K7 pre-shim diffs
   = 161 lines deleted, 22 inserted. Mech 50 was the *cap*; without
   it they'd score >100. Append-only shim eliminates the class.
2. *Fab-UUIDs on prefetch-bypass dial (R18).* K7 d6_tool inserted
   =[12345678-1234-5678-1234-567812345678]= when prefetch payload
   was withheld. =primary: -13, fab=4= flagged it, but only because
   the harness compared against =known_ids=. Without prefetch the
   model has no fabrication anchor.
3. *Nested-bracket disaster (R18 K6/K7 layer3, R19 K1).* When the
   source already contains =[[*TODO ... Phase 2026-05.20 ...][...]]=
   and the model re-wraps the inner phrase with another
   =[[id:...][...]]=, result = =[[id:...][[[id:...][...]]]]=. Org
   parser silently broken; mech rewarded the wrap insertion.
4. *Table-row pipe loss (R18 K6, K9).* Replacing =| =verbatim= |=
   with =[[id:UUID][verbatim]] |= drops the leading pipe. Cell is no
   longer a valid table row; mech saw 1 wrapped link and rewarded.
5. *Provider =IncompleteRead= layer (R17, R18, R19).* DeepInfra
   dropped K7 after 297 bytes; GMICloud dropped K13 across 3
   retries for $0.00 cost (half-open socket); R19 had 12 across
   K2/K7/K8/K9. Pre-warm + provider failover is the only fix.

* R20+ recommendations from these extremes

*Summary.* Six small validators close most of the visible quality
gap; one prompt change for =bt_pt=, one tool primitive
(=append_at_eof=), and provider failover handle the rest.

*Expanded.*

** Validators (ship as =scripts/quality_lint.py=, fold into mech)

1. *Bracket-balance lint (-3/event).* Regex over inserted lines:
   =\]\)= without paired =\[\[=, =\]\]\]\]= or deeper, =\[\[\[\[=
   chains. Already in R18 judge §6.
2. *Fab-UUID validator (hard 0).* For every inserted
   =[[id:UUID][...]]=, require =UUID in prefetch.known_ids=. K7's
   =bt_pt= cells become unrunnable.
3. *Pipe-balance lint for table rows (-2/event).* Diff lines inserted
   into a table region (between =|---+---|= rules) without leading =|=
   are flagged.
4. *Heading-duplication detector (-5/event).* Track headline-stripped
   form of every modified =* / ** / ***= line in inserted vs deleted
   text; if a heading has both a deleted form and a label-truncated
   inserted form, dock 5 (catches K1 R19 =Tier 1 — Customize= dup).
5. *Python AST guard for unreachable code (-10/event).* For =.py=
   diffs, =ast.parse= the post-edit file, walk function bodies, flag
   any statement after an unconditional =return= (catches K1 R18 B7).
6. *Append-only enforcement on B11-shape tasks.* When manager
   classifies =stakes: high= and brief says "add a new DEC heading",
   gate =edit_file=: if =old_string= matches an existing =DEC-NNN=
   body, refuse + require =append_at_eof=.

** Prompt changes

- *Add explicit "use only the IDs in <prefetch>" sentence to the
  brief when prefetch payload is withheld* (=bt_pt= dial). K7
  defaulted to =[12345678-...]= as a syntactic placeholder; the
  =bt_pt= brief currently relies on the model voluntarily calling
  the prefetch tool, with no forcing function if it doesn't.
- *Re-order brief: prefetch matchset BEFORE task description.*
  R17 moved stable bytes first for caching; double down by making
  the matchset the *first* user-visible content so the model can't
  frame the task without it.
- *State the no-op trap on B20-shape tasks.* R18 quality judge gave
  4-way mech-0 cells quality 18 because they correctly abstained.
  Briefs should say "if invariant already satisfied, write nothing
  and return =OK_NOOP=" so abstention is a positive answer.

** Tool changes

- *Add =append_at_eof(path, content)= as a first-class primitive.*
  Currently must be expressed as =edit_file= with last 80 bytes as
  =old_string=. All R17/R18/R19 K5 B11 wins used a Claude-only
  equivalent; FOSS models needed it for parity.
- *Add =read_lines(path, start, end)= to complement =read_file=.*
  K1/K11 B11 cells repeatedly read the full 50KB =decisions.org= to
  find EOF — wastes ~6KB context. Range read would cut K11's $1.57
  R17 cost and make B11-shape tasks portable to smaller-context
  FOSS models.
- *Provider failover layer.* Retry on second-best provider when
  first returns =IncompleteRead= before scoring 0. Salvages ~25
  cells across R17-R19.
