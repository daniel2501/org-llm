* Cross-cutting — patterns common to *best* cells

*Summary.* Five repeatable traits across all 5 rounds.

*Expanded.*

1. *Prefetch payload with canonical IDs is load-bearing.* Every
   high-quality B1/B11 cell used the manager's =known_ids= (R15 K1:
   99 IDs available, 7 used). =bt_pi= (inlined) and =bt_pt= (tool-only)
   both produced systematic 0s.
2. *=bt_pb_m1_tb_s1= dial dominates.* Every top-cell row above is
   on this dial. =tm= (minimal tools) and =m0= (no manager) produce
   non-zero best cells with measurable degradation.
3. *Append-only beats re-wrap on long files.* K5 R17/R18/R19 B11
   always appends at EOF; K1/K7 R16 B11 used =edit_file old/new= to
   *replace* DEC-019 and got destructive diffs.
4. *File <300 lines correlates with success.* B1 (324 lines), B25
   (new ~12-line elisp), B26 (5-line defcustom add) produce most
   top-3 cells. B11 (~1600-line decisions.org) only succeeds under
   append-only enforcement.
5. *Models: K1 + K5 + K8 only.* K1-qwen30 = cost pareto, K5-claude
   = quality ceiling, K8-deepseekV3 = cheap floor with respectable
   quality. K11-qwen3coder is third FOSS with a 50-240x cost penalty.

* Cross-cutting — patterns common to *worst* cells

*Summary.* Five failure shapes; first four are model defects, fifth
is harness/provider.

*Expanded.*

1. *Whole-section overwrite on B11 (R16).* K1 + K7 pre-shim = 161 del,
   22 ins. Mech 50 was the *cap*; uncapped they'd score >100.
2. *Fab-UUIDs on prefetch-bypass (R18).* K7 d6_tool inserted
   =[12345678-1234-5678-1234-567812345678]= when prefetch payload
   was withheld. =primary: -13, fab=4= flagged only because the
   harness compared against =known_ids=. Without prefetch, no anchor.
3. *Nested-bracket disaster (R18 K6/K7 layer3, R19 K1).* When source
   already contains =[[*TODO ... Phase 2026-05.20 ...][...]]= and the
   model re-wraps the inner phrase, result =
   =[[id:...][[[id:...][...]]]]=. Org parser silently broken; mech
   rewarded the wrap insertion.
4. *Table-row pipe loss (R18 K6, K9).* =| =verbatim= |= →
   =[[id:UUID][verbatim]] |= drops the leading =|=. No longer a
   valid table row; mech saw 1 link and rewarded.
5. *Provider =IncompleteRead= (R17, R18, R19).* DeepInfra dropped
   K7 after 297B; GMICloud dropped K13 across 3 retries at $0.00
   (half-open socket); R19 had 12 drops across K2/K7/K8/K9. Pre-warm
   + failover is the only fix.

* R20+ recommendations from these extremes

*Summary.* Six small validators close most of the visible quality
gap; one prompt change for =bt_pt=, one tool primitive
(=append_at_eof=), and provider failover handle the rest.

*Expanded.*

** Validators (ship as =scripts/quality_lint.py=, fold into mech)

1. *Bracket-balance lint (-3/event).* Regex over inserted lines:
   =\]\)= without paired =\[\[=, =\]\]\]\]+= chains, =\[\[\[\[+= chains.
2. *Fab-UUID validator (hard 0).* Every inserted =[[id:UUID][...]]=
   must have =UUID in prefetch.known_ids=. Makes K7 =bt_pt= cells
   unrunnable rather than mech-rewardable.
3. *Pipe-balance lint for table rows (-2/event).* Diff lines inserted
   into a table region (between =|---+---|= rules) without leading
   =|= are flagged.
4. *Heading-duplication detector (-5/event).* If a modified =* / ** /
   ***= line has both a deleted form and a label-truncated inserted
   form, dock 5 (catches K1 R19 =Tier 1 — Customize= dup).
5. *Python AST guard for unreachable code (-10/event).* For =.py=
   diffs, =ast.parse= post-edit file, flag statements after an
   unconditional =return= (catches K1 R18 B7).
6. *Append-only enforcement on B11-shape tasks.* When manager
   classifies =stakes: high= and brief says "add a new DEC heading",
   gate =edit_file=: if =old_string= matches an existing =DEC-NNN=
   body, refuse and require =append_at_eof=.

** Prompt + tool changes

- *Brief: "use only IDs in <prefetch>"* when prefetch payload is
  withheld (=bt_pt= dial). K7 defaulted to =[12345678-...]= as a
  syntactic placeholder; current brief has no forcing function.
- *Re-order brief: prefetch matchset BEFORE task description.* R17
  moved stable bytes first for caching; double down so the model
  can't frame the task without the matchset.
- *State the no-op trap on B20-shape tasks.* "If invariant already
  satisfied, write nothing and return =OK_NOOP=" — abstention as
  a positive answer.
- *=append_at_eof(path, content)= as first-class primitive.*
  Currently must be =edit_file= with last 80 bytes of file as
  =old_string=. All R17/R18/R19 K5 B11 wins used a Claude-only
  equivalent; FOSS parity.
- *=read_lines(path, start, end)=.* K1/K11 B11 cells repeatedly
  read the full 50KB =decisions.org= to find EOF — wastes ~6KB
  context. Cuts K11's $1.57 R17 B11 cost.
- *Provider failover.* Retry on second-best provider on
  =IncompleteRead= before scoring 0; salvages ~25 cells R17-R19.
