** Dial pool corrections

- *DROP* =bt_pi_m1_tb_s1= (prefetch_inline) — broke K1 plan parser;
  K11 -2 vs =pb=. Inlining the brief into the prefetch payload is a
  measured loss.
- *DROP* =bt_pt_m1_tb_s1= (tool surface tight) — both K1 and K11
  scored 0; tool roster too narrow for cross-link spec.
- *KEEP* =bt_pb_m1_tb_s1= as canonical baseline.
- *KEEP* =bt_pb_m1_tm_s1= (tool_minimal) — K1 +5 over baseline; cheap
  and competitive for trivial tasks.
- *KEEP* =bl_pb_m1_tb_s1= (loose-brief) — K1 +0, K11 -4; close call,
  retain for one more round to confirm.
- *DECIDE* =bt_pb_m0_tb_s1= (no-manager) — K1 -8 from R16, K11 +4. A
  layer that earns its keep for some variants, not others.

** R18 features to add

- *Provider failover* — when first provider returns IncompleteRead,
  retry on second-best provider before scoring 0. Would have salvaged
  K7 + K13 cells.
- *Pre-launch worktree serialization* — 3 worktree-add failures hit
  K2/K8/K13 in R17 due to git's lack of concurrent-add safety. Add a
  filesystem-level mutex around =git worktree add=.
- *Brief-counts validator* — K11 and K1 both inserted 6 links when
  brief said "exactly 5". Either tighten the brief language or add a
  post-edit count gate.
- *Author-line lint* — K11 fabricated =Daniel Mendler / GPL-3.0= on
  B25 elisp file. Add a fabrication-detector for license headers /
  attributions in newly-created files.
